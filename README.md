# Boliginfo
A Flask based website for showing and filtering house data based in Denmark !


## Scaffold
![Drawing sketchpad](https://github.com/SanderLahoz/Boliginfo/assets/73191374/8c7daa7f-fc6e-4195-92c2-9346c1439687)


### Steps
1. Create a Python Virtual Environment `python3 -m venv ~/.venv` or `virtualenv ~/.venv`
2. Create empty files: `Makefile`, `requirements.txt`, `.env`, `Dockerfile`, and `sourcefiles / packages`
3. Populate `Makefile`
4. Setup Continuous Integration (Github Actions), i.e. check code for issues like lint errors
5. Build commandline tool using python fire library `./bolig-command.py` to test logic
